## Ranking rounds

- Same 5 secret weeks per level for every team. Ranked in a round = all 5
  played, each ≥ 90% on time; margin = sum of the 5.
- House teams: *House starter* (the kit starter) and *House best* (organisers'
  best system) play every round.
- Rounds **do not count** for the final; they show where you stand.

## The final

- One secret level 8 week; each team has its own copy (no competing for cars
  or drivers).
- Start your system before 08:00 (`--final` waits). It must run to the end; if
  it stops, restart at once — it rejoins the same week.
- Run on a machine with a steady connection; the server is near Stockholm.
- Result = gross margin; < 90% on time or no orders = not ranked.
- Top 10 ranked by margin present to the jury. After that, margin no longer
  counts.

## What the jury looks for

- **Elegant:** a simple idea doing a lot of the work; few parts, each with a
  stated reason.
- **Clear:** they can follow how the system decides, from talk and code.
- **Creative:** an unexpected way to see dealers, drivers or the week.
- **Robust:** does well on unseen weeks (show results over many weeks);
  survives restarts, slow network, surprises.

## What to submit (by Sun 10:00, every team)

1. Submission hash (from `/team`).
2. Link to the code.
3. Presentation: 5–10 slides or a short video.

## Presentation

- For each big idea: **the idea** (what and when), **why** (what you saw), **the
  effect** (margin and on-time share with vs without, on the same weeks).
- Good topics: which cars you win and at what price, how you set fees, when
  you combine cars.
- Also: final result, best ranking round, what didn't work, what would break
  the system.
- Style: start with the answer; one idea per slide (claim + evidence); numbers
  with units and a comparison (e.g. "€12,551 a week vs −€67,177 for the
  starter, same 20 level 8 weeks"); show decision rules/formulas/diagrams, not
  code screenshots; use the challenge's words (dealer, request, gig, fee,
  typical fee, deadline); cut filler; state limits.
